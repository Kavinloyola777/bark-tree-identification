# 🌳 BarkID – Tree Species Identification & CO₂ Estimator

## 📌 Project Overview
This project uses Deep Learning to identify tree species based on bark images and estimate their CO₂ absorption using Thinai ecological classification.

## 🚀 Features
- Bark-based tree identification
- CO₂ absorption estimation
- Thinai region classification
- Interactive web application

## 🧠 Model
- Hybrid Model (ResNet50V2 + CNN)
- Multi-class classification (24 species)

## 📂 Dataset
- 5 Thinai regions
- 50+ images per class

## ⚙️ Tech Stack
- Python
- TensorFlow / Keras
- Streamlit
- Plotly

## 🌐 Deployment
Model is hosted externally (Google Drive) and loaded dynamically.
